# Market Basket Analysis 🛒

Market Basket Analysis project using **Apriori** and **Machine Learning** to identify customer buying patterns and generate business insights from transactional data.

## 🚀 Technologies
- **Language:** Python
- **Libraries:** Pandas, Scikit-learn, Mlxtend, Matplotlib, Seaborn, Plotly

## 📊 Features
- **Data Cleaning:** Handling missing values and data optimization.
- **Exploratory Data Analysis (EDA):** Visualizing peak shopping hours and top products.
- **Association Rules:** Identifying relationships between products.
- **Apriori Algorithm:** Generating frequent itemsets and business insights.
- **Predictive Modeling:** Using Machine Learning for customer segmentation (Clustering).

## 📂 Dataset Requirement
The dataset used in this project is too large for GitHub's upload limit. 
1. **Download** the dataset from here: [Kaggle Supermarket Dataset](https://www.kaggle.com/code/smohsensadeghi/supermarket-dataset-for-predictive-marketing-2023/input)
2. **Rename** the file to `ECommerce_consumer behaviour.csv` (if it has a different name).
3. **Place** the file in the same folder as the `main.py` script before running the code.
